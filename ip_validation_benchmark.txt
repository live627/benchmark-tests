Understanding the TP / TN / FP / FN columns:
  TP = True Positive   → correctly accepted a valid IP.
  TN = True Negative   → correctly rejected an invalid IP.
  FP = False Positive  → incorrectly accepted an invalid IP (too lenient).
  FN = False Negative  → incorrectly rejected a valid IP (too strict).

A perfect validator has FP = 0 and FN = 0, with high TP and TN counts.
Use these metrics to see whether a method is overly permissive or overly restrictive.
